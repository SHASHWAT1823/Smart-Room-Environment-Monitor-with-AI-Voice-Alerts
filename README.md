
# Smart Room Environment Monitor with AI Voice Alerts

An AI powered IoT monitoring system built using Raspberry Pi Zero W and AWS.

## Features

- Temperature & Humidity Monitoring (DHT22)
- Soil Moisture Monitoring
- AWS IoT Core (MQTT over TLS)
- AWS Lambda
- Amazon DynamoDB
- Amazon Polly
- Amazon Transcribe
- AWS SNS Alerts
- Flask Dashboard
- AI-powered Voice Alerts
- Voice Query Support

## Hardware

- Raspberry Pi Zero W
- DHT22
- Soil Moisture Sensor
- ADS1115 ADC
- USB Microphone
- USB Speaker

## AWS Services

- AWS IoT Core
- AWS Lambda
- DynamoDB
- Amazon Polly
- Amazon Transcribe
- Amazon S3
- Amazon SNS
- AWS IoT Device Shadow
